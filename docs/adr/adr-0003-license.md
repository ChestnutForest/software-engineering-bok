# ADR-0003 ライセンス

> **草案である。** 選択肢を並べた。決めたら `status` を `accepted` に変え、
> `LICENSE` を差し替える。

## 決めること

現在は MIT である。**文書リポジトリには適さない。**

| | MIT License | 本リポジトリの実態 |
| --- | --- | --- |
| 対象 | "the Software" | 文書。ソフトウェアではない |
| 許諾 | 複製、改変、再配布、サブライセンス、販売 | 許諾できる範囲がそもそも限られる |

扱う対象には ISO 規格、CMMI、PSP/TSP、RUP、OMG 仕様書が含まれる。
本文を転記しない方針であっても、**MIT は「この成果物すべてを自由に再配布してよい」と
宣言する。** 引用や図表が1つでも混ざれば、宣言と実態が食い違う。

## 選択肢

| 選択肢 | 性質 | 向くとき |
| --- | --- | --- |
| **CC BY 4.0** | 表示を条件に再利用を許す | 文書向け。第一候補 |
| CC BY-SA 4.0 | 上記に継承条件を加える | 派生物も同条件にしたいとき |
| CC0 | 権利を放棄する | 制約を一切かけたくないとき |
| MIT のまま | — | **推奨しない。対象が合わない** |

## コードと文書を分ける

`scripts/generate-views.mjs` があるため、実務的には次の形になる。

```
LICENSE            → CC BY 4.0（文書）
scripts/LICENSE    → MIT（コード）
```

README にどちらがどこに適用されるかを1行で書く。

## 一次資料との関係

**本リポジトリのライセンスは、収録した一次資料の条件を上書きしない。**

たとえば IPA の機能要件の合意形成ガイドは**複製可・翻案不可**である。
本リポジトリを CC BY 4.0 にしても、ガイドの本文を翻案してよいことにはならない。

README と各エントリに、**一次資料の `rights` を優先して確認する**旨を明記する。
