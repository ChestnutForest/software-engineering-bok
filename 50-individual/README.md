## TDD の位置づけ

**TDD は個人の規律に限らない。** チームのコードベースに対する進め方でもある。
この階層に置いてあるが、`applicable_to_solo: true` は「個人でも使える」という意味であって
「個人専用」ではない。

## 仕様駆動開発を置かない

AI エージェントへの指示の与え方であり、個人の規律ではない。
[`../40-software/ai-assisted/`](../40-software/ai-assisted/) にある。
