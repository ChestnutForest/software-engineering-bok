## ソフトウェア工学との境界

**SEBoK は別分野（システムズエンジニアリング）の知識体系である。**
SWEBOK Guide は自らの目的に「他分野との境界を明確にすること」を掲げ、
システムズエンジニアリングは定義せず関連分野として扱っている。

本リポジトリはソフトウェア工学を対象とする。したがって SEBoK は
**本文を置かず、リンクと境界の記述だけを置く。**

SysML も同じ側にある。OMG の SysML はシステムズエンジニアリング向けの
UML プロファイルである。

## 注意

この階層の存否は ADR-0002 の未決事項5（ソフトウェア工学以外を含むか）に依存する。
