# 10-organization — 組織が採る枠組み

## 置くもの

組織単位で採用・評定・認証される枠組み。開発手法ではない。

| 項目 | 種別 |
| --- | --- |
| [CMMI](cmmi.md) | 評定の枠組み |
| [People CMM](people-cmm.md) | 評定の枠組み |
| [ISO 9001](iso-9001.md) | 標準（要求事項） |
| [ISO/IEC 90003](iso-iec-90003.md) | 指針 |

## 置かないもの

- チームの進め方（→ `30-team/`）
- 個人の規律（→ `50-individual/`）

## 注意

**ここにあるものは、個人プロジェクトでは適用できない。** CMMI の評定も
ISO 9001 の認証も組織単位の制度である。したがって `applicable_to_solo: false` とし、
**選択肢ではなく参照として登録する。**

`standard` と `guideline` を区別する。ISO 9001 は適合が判定される要求事項であり、
ISO/IEC 90003 は適用の指針である。**公的機関が出したものをすべて `standard` と呼ばない。**
