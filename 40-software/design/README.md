## 二次情報に存在する2つの誤り

姉妹プロジェクトが調査の過程で見つけ、一次資料で訂正した誤りである。
**本リポジトリで繰り返さない。**

| 誤り | 正しくは |
| --- | --- |
| 機能要件の合意形成ガイドの技術領域を**7つ**とする | 6技術領域＋概要編の全7編。**概要編は技術領域ではない** |
| 同ガイドの対象工程を**要件定義**とする | **外部設計工程** |
