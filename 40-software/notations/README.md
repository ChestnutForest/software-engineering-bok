## 記法はプロセスではない

**UML はプロセスを規定しない。** 記法であって開発手法ではない。

システムを記述する SysML は [`../../20-system/sysml.md`](../../20-system/sysml.md)、
プロセスを記述する PFD と SPEM は
[`../../30-team/process-modeling/`](../../30-team/process-modeling/) にある。
**記述の対象が違うものを同じ場所に置かない。**

## 形式手法ではない

ここにあるものは `semi-formal` である。構造は定まるが、意味論は数学的に
定義されていない。`formal` なものは [`../formal-methods/`](../formal-methods/) にある。
