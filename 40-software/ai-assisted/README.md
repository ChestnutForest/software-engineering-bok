## 仕様駆動開発と TDD を並置しない

由来も対象も異なる。仕様駆動開発は AI エージェントへ仕様を渡す進め方であり、
TDD は XP 由来のプラクティスである。TDD は
[`../../50-individual/test-driven-development.md`](../../50-individual/test-driven-development.md)
にある。

仕様駆動開発は**個人の規律ではない。** エージェントへの指示の与え方である。
